# 设计规范

本文档定义云枢面板的设计系统，包括设计原则、Design Token、组件规范、布局规范和交互规范，确保产品视觉和体验的一致性。

## 设计原则

### 1. 简洁高效

- 界面简洁，去除不必要的装饰元素
- 操作路径最短，常用功能一键可达
- 信息层级清晰，重点内容突出
- 减少用户认知负担

### 2. 专业可靠

- 视觉风格专业、稳重，适合服务器管理场景
- 数据展示准确、实时、可信
- 操作有明确反馈，危险操作有二次确认
- 错误状态有清晰提示和解决方案

### 3. 一致统一

- 全局使用统一的设计语言和组件
- 相同功能在不同模块中表现一致
- 配色、间距、字体、图标遵循统一规范
- 交互模式统一，降低学习成本

### 4. 响应式适配

- 适配不同屏幕尺寸（桌面端为主，兼顾平板）
- 侧边栏可折叠，内容区自适应
- 表格在小屏幕下可横向滚动
- 弹窗和抽屉适配视口大小

## 布局规范

### 整体布局

```
┌─────────────────────────────────────────────────────┐
│  顶栏 (TopBar) 高度: 56px                            │
│  ┌──────────┬──────────────────────────┬──────────┐ │
│  │ Logo+名称 │     面包屑/页面标题       │ 用户菜单  │ │
│  └──────────┴──────────────────────────┴──────────┘ │
├────────┬────────────────────────────────────────────┤
│        │                                            │
│ 侧边栏  │              内容区 (Content)              │
│ 240px  │         padding: 24px                      │
│ (可折叠  │                                            │
│  为64px)│                                            │
│        │                                            │
└────────┴────────────────────────────────────────────┘
```

### 侧边栏

- **宽度**：展开 240px，折叠 64px
- **背景**：`--color-card`（白色），右侧边框 `--color-border`
- **菜单项**：高度 40px，左右内边距 16px，图标 18px
- **选中态**：背景 `--color-primary` 10% 透明度，文字 `--color-primary`，左侧 3px 主色条
- **悬停态**：背景 `rgba(0,0,0,0.04)`
- **分组**：模块间用 8px 间距分隔，分组标题 12px 灰色文字

### 顶栏

- **高度**：56px
- **背景**：`--color-card`（白色），底部边框
- **左侧**：Logo（24px）+ 产品名称（16px Medium）
- **中间**：面包屑导航（14px，分隔符 `/`）
- **右侧**：搜索、通知铃铛、用户头像+名称、下拉菜单

### 内容区

- **内边距**：24px
- **页面标题**：20px Medium，底部间距 16px
- **页面描述**：14px text-2，底部间距 20px
- **卡片间距**：16px（同排）、20px（上下排）

### 栅格系统

使用 24 栏栅格（Naive UI 内置）：

| 断点 | 宽度 | 用途 |
|------|------|------|
| xs | < 768px | 手机（适配，非主要目标） |
| sm | ≥ 768px | 平板竖屏 |
| md | ≥ 992px | 平板横屏 / 小屏笔记本 |
| lg | ≥ 1200px | 标准桌面 |
| xl | ≥ 1920px | 大屏 / 超宽屏 |

## 组件规范

### 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 (Primary) | 主色背景，白色文字 | 主要操作、表单提交 |
| 次按钮 (Default) | 白色背景，灰色边框 | 次要操作、取消 |
| 虚线按钮 (Dashed) | 白色背景，虚线边框 | 添加、新建 |
| 文字按钮 (Text) | 透明背景，主色文字 | 表格行内操作、链接 |
| 危险按钮 (Error) | 红色背景，白色文字 | 删除、危险操作 |

#### 按钮尺寸

| 尺寸 | 高度 | 内边距 | 字号 | 用途 |
|------|------|--------|------|------|
| small | 28px | 0 10px | 12px | 表格行内、紧凑空间 |
| medium | 34px | 0 14px | 14px | 标准按钮（默认） |
| large | 40px | 0 18px | 14px | 弹窗底部、重要操作 |

#### 按钮规范

- 同一操作区域最多 1 个主按钮
- 危险操作使用危险按钮，并需二次确认
- 按钮文字使用动词，不超过 4 个汉字
- 加载中状态显示 loading 图标，禁用点击
- 禁用状态透明度 50%，不可点击

### 表格

- **表头**：背景 `rgba(0,0,0,0.02)`，文字 12px text-2，高度 44px
- **行高**：48px（标准），40px（紧凑）
- **行悬停**：背景 `rgba(0,0,0,0.02)`
- **斑马纹**：可选，偶数行背景 `rgba(0,0,0,0.015)`
- **边框**：底部边框 `--color-border`
- **空状态**：居中显示图标 + "暂无数据"文字
- **加载中**：骨架屏或 loading 遮罩

#### 表格列规范

| 列类型 | 宽度 | 对齐 | 说明 |
|--------|------|------|------|
| ID/序号 | 60-80px | 居中 | 固定宽度 |
| 名称/标题 | 自适应 | 左对齐 | 主要信息列 |
| 状态 | 100px | 居中 | 标签展示 |
| 时间 | 160-180px | 左对齐 | 固定宽度 |
| 操作 | 120-200px | 居中 | 文字按钮组 |

### 表单

- **标签**：14px，右对齐，宽度 100px，间距 12px
- **输入框**：高度 34px，圆角 4px，边框 `--color-border`
- **输入框聚焦**：边框主色，外发光 `0 0 0 2px rgba(24,160,88,0.2)`
- **必填标记**：标签前红色 `*`
- **错误提示**：输入框下方 12px 红色文字
- **帮助文字**：输入框下方 12px text-3 灰色文字
- **表单项间距**：垂直 20px
- **表单宽度**：最大 600px，超出用多列布局

### 标签 (Tag)

| 类型 | 颜色 | 用途 |
|------|------|------|
| success | 绿色 | 运行中、成功、已启用 |
| warning | 橙色 | 待处理、执行中 |
| error | 红色 | 异常、失败、已停止 |
| info | 蓝色 | 信息、未配置 |
| default | 灰色 | 中性状态、分类 |

- 标签高度 22px，内边距 0 8px，字号 12px，圆角 4px
- 状态标签使用圆点 + 文字形式

### 卡片

- **背景**：白色，圆角 6px，阴影 `--shadow-sm`
- **内边距**：16-24px
- **卡片标题**：16px Medium，底部 12px 间距
- **卡片头部**：可包含标题、描述、操作按钮
- **卡片悬浮**：阴影变为 `--shadow-md`（可选交互）

### 弹窗 (Modal)

- **宽度**：小 480px，中 600px，大 800px
- **标题栏**：高度 56px，18px Medium 标题，右侧关闭按钮
- **内容区**：内边距 24px，最大高度 60vh，超出滚动
- **底部操作栏**：高度 64px，右对齐按钮组，按钮间距 12px
- **遮罩**：`rgba(0,0,0,0.5)`
- **关闭方式**：右上角 X、遮罩点击、ESC 键、取消按钮

### 抽屉 (Drawer)

- **宽度**：360px（窄）、520px（标准）、720px（宽）
- **从右侧滑入**，动画 250ms
- **标题栏**和底部操作栏同弹窗规范
- 适用于详情查看、快速编辑、设置面板

### 消息提示

| 类型 | 组件 | 用途 | 位置 |
|------|------|------|------|
| 全局消息 | Message | 操作成功/失败提示 | 顶部居中，3秒自动消失 |
| 通知 | Notification | 告警、系统通知 | 右上角，可手动关闭 |
| 对话框 | Dialog | 危险操作确认 | 居中模态 |
| 表单错误 | FormItem | 表单校验失败 | 输入框下方 |

## 暗色模式（规划中）

暗色模式设计规范将在后续版本中补充，主要原则：

- 背景色：`#1a1a1a`（页面）、`#242424`（卡片）
- 文字色：反色处理，主要文字 `rgba(255,255,255,0.9)`
- 主色保持不变，调整亮度以适配暗色背景
- 通过 CSS 变量切换，无需修改组件代码
- 跟随系统设置或用户手动切换

## 无障碍设计

- 所有交互元素可通过键盘操作（Tab 导航、Enter 确认、ESC 关闭）
- 焦点状态有明显的视觉指示（外发光）
- 图标按钮有 `aria-label` 属性
- 颜色不是唯一的信息传达方式（状态同时用文字和颜色）
- 文字对比度符合 WCAG AA 标准（4.5:1）
- 表单错误有明确的文字提示，不仅是红色边框
- 动画支持 `prefers-reduced-motion` 媒体查询
