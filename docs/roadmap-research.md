## 二、功能建议清单（按价值/成本排序）

### 第一档：低成本高价值（建议 1-2 个迭代内完成）

| # | 功能 | 说明 | 参考对象 | 预估工作量 |
|---|------|------|----------|-----------|
| 1 | **资源阈值告警规则** | CPU/内存/磁盘/连接数阈值 → 复用已有告警+邮件通道，规则引擎存 settings | Uptime Kuma | 小 |
| 2 | **SSL 到期提醒** | 计划任务扫描证书 → 邮件通知（30/15/7 天梯度） | 1Panel | 小 |
| 3 | **Docker 定时清理** | 新计划任务类型：清理停止容器/悬空镜像/构建缓存（CapRover 特色，防磁盘爆满） | CapRover | 小 |
| 4 | **数据库备份加密** | 备份任务可选 AES-GCM 加密 + 密钥托管 | 1Panel v2 | 小 |
| 5 | **文件回收站** | 文件删除进 `.recycle/`（7 天自动清），防误删 | 1Panel | 中 |
| 6 | **网站拨测** | HTTP(S)/TCP/Ping 拨测 + 状态码/关键词校验 + 告警，可视化可用性时间线 | Uptime Kuma | 中 |

### 第二档：中等成本（差异化竞争力，建议排期）

| # | 功能 | 说明 | 参考对象 | 预估工作量 |
|---|------|------|----------|-----------|
| 7 | **Compose 编排管理** | 可视化栈管理：在线编辑 compose、up/down/logs、模板导入导出——复用已有 Docker SDK | Dockge/1Panel | 中 |
| 8 | **容器镜像在线构建** | Dockerfile 编辑器 + 构建参数 + 构建日志流（buildkit API） | 1Panel/Coolify | 中 |
| 9 | **Git 推送部署** | Webhook 接收 → 拉取仓库 → 构建（静态/Node/Dockerfile）→ 发布到站点目录。PaaS 化第一步 | Coolify | 大 |
| 10 | **WAF 基础版** | nginx 层：CC 防护（limit_req 动态生成）、恶意 UA 拦截、GeoIP 封锁、攻击日志 | 宝塔/1Panel | 大 |

## 三、推荐实施路线

```
v1.1（稳定性+低成本告警）: #1 阈值告警、#2 SSL提醒、#3 Docker清理、#4 备份加密
v1.2（差异化能力）        : #6 网站拨测、#7 Compose编排、#5 文件回收站
v1.3（PaaS 化开端）       : #8 镜像构建、#9 Git 部署
v2.0（战略方向讨论）      : #10 WAF、#11 进程守护、#13 多节点、#14 AI 助手
```

## 四、依据摘要

- **1Panel**（32k★，本项目最直接对标）：社区版已覆盖本项目全部基础功能；其付费点（WAF/防篡改/报表/多节点）即本项目的机会窗口；v2 转向 AI 管理
- **Coolify**（44k★）：Git 部署 + Compose 原生支持 + 零停机发布是其核心吸引力——面板类项目 PaaS 化已被验证是最大增量方向
- **CapRover**：Docker 定时清理是刚需小功能；明文 secret 存储被社区诟病——本项目 API Key 哈希存储已是加分项
- **Uptime Kuma**（60k★）：拨测+状态页+多渠道告警是运维面板最常被外挂的需求，内置可形成闭环
