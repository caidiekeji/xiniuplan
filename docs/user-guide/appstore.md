# 应用商店

应用商店模块提供一键安装常用 Web 应用的能力，内置丰富的应用模板，涵盖博客系统、内容管理、开发工具、协作平台等类别。每个应用基于 Docker 容器运行，安装过程自动完成镜像拉取、容器创建、环境配置和启动。

## 功能概览

- 应用浏览与分类筛选
- 应用搜索
- 一键安装应用
- 已安装应用管理
- 应用状态查看
- 应用卸载
- 应用源管理（支持多应用源）

## 应用列表

进入"应用商店"页面，展示所有可用应用。

### 列表信息

| 字段 | 说明 |
|------|------|
| 应用标识 | 应用唯一 key（如 `wordpress`、`nextcloud`） |
| 名称 | 应用显示名称 |
| 描述 | 应用简介 |
| 类别 | 应用分类（博客、CMS、开发工具等） |
| 版本 | 应用版本号 |
| 图标 | 应用图标 |
| 安装状态 | 是否已安装 |

### 筛选与搜索

- **分类筛选** — 按应用类别筛选，如"博客"、"数据库"、"开发工具"
- **关键词搜索** — 输入应用名称或描述关键词搜索
- **应用源筛选** — 按应用来源筛选（配置多应用源时可用）

## 安装应用

### 操作步骤

1. 在应用列表中找到要安装的应用
2. 点击应用卡片查看详情
3. 点击"安装"按钮
4. 如应用需要环境变量，填写配置参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 端口 | 应用对外服务端口 | 8080 |
| 数据库 | 如应用需要，选择已有数据库实例 | mysql-1 |
| 管理员账号 | 应用管理员用户名 | admin |
| 管理员密码 | 应用管理员密码 | 自定义 |
| 数据目录 | 应用数据持久化目录 | /data/apps/nextcloud |

5. 点击"确认安装"
6. 系统自动执行：拉取镜像 → 创建容器 → 配置环境 → 启动容器
7. 安装完成后状态变为 `running`

> 安装时间取决于镜像大小和网络速度，大型应用可能需要几分钟。

### 安装后操作

应用安装成功后：

1. 查看应用详情获取访问地址（通常为 `http://服务器IP:端口`）
2. 如应用有 Web 安装向导，按向导完成初始化
3. 建议在网站管理中为应用配置域名和 SSL 证书
4. 在防火墙中开放应用端口（如未自动开放）

## 已安装应用

切换到"已安装"标签页，查看所有已安装的应用：

| 列 | 说明 |
|----|------|
| 应用名称 | 应用显示名称 |
| 版本 | 安装的版本号 |
| 安装路径 | 应用数据目录 |
| 状态 | running / stopped / error |
| 容器状态 | 底层 Docker 容器状态 |
| 安装时间 | 安装完成时间 |
| 操作 | 查看状态/卸载 |

## 应用状态

点击应用的"状态"按钮，查看应用详细运行状态：

- 应用基本信息（名称、版本、安装路径）
- 容器状态（运行中/已停止）
- 容器 ID
- 端口映射
- 环境变量
- 创建和更新时间

## 卸载应用

1. 在已安装应用列表中找到要卸载的应用
2. 点击"卸载"按钮
3. 在确认对话框中确认
4. 系统将停止并删除应用容器
5. 应用数据目录默认保留，如需彻底删除请手动删除数据目录

> **注意**：卸载应用不会删除应用产生的数据。如需完全清理，请在卸载后手动删除安装目录中的数据。

## 应用源管理

云枢面板支持配置多个应用源，可从不同来源获取应用模板。

### 应用源列表

展示已配置的所有应用源：

- 源名称
- 源地址（URL）
- 状态（正常/异常）
- 应用数量
- 最后同步时间

### 添加应用源

1. 点击"添加应用源"
2. 填写源名称和源地址（URL，指向应用清单 JSON）
3. 点击保存，系统自动同步应用列表

### 同步应用源

点击"同步"按钮，从应用源地址重新获取最新应用清单。

### 删除应用源

删除不再使用的应用源。删除后该源下的应用将不再显示，但已安装的应用不受影响。

## 常见使用场景

### 场景一：快速搭建博客

1. 在应用商店搜索 `wordpress` 或 `typecho`
2. 点击安装，填写端口和数据库信息
3. 等待安装完成
4. 访问 `http://服务器IP:端口` 完成博客初始化
5. 在网站管理中配置域名和 SSL

### 场景二：搭建私有云盘

1. 搜索 `nextcloud`
2. 安装时配置数据目录（建议选择空间充足的分区）
3. 安装完成后访问并创建管理员账号
4. 配置域名和 SSL，通过 HTTPS 安全访问
5. 在客户端中配置同步

### 场景三：安装开发工具

1. 搜索 `gitea`（Git 托管）或 `jenkins`（CI/CD）
2. 安装时配置端口和数据目录
3. 安装完成后访问初始化
4. 配置防火墙开放端口
5. 结合 Web 终端和计划任务实现自动化部署
