# 文件管理器

文件管理器提供基于 Web 的服务器文件管理功能，支持文件浏览、上传下载、在线编辑、压缩解压、搜索等常用操作，让您无需 SSH 即可轻松管理服务器文件。

## 功能概览

- 目录浏览与导航
- 文件上传与下载
- 在线创建文件和目录
- 文本文件在线编辑
- 文件重命名、复制、移动、删除
- 文件压缩（zip）与解压
- 文件搜索（支持正则表达式）
- 批量操作

## 目录浏览

### 界面布局

文件管理器主界面分为：

- **路径栏** — 显示当前路径，支持点击面包屑导航
- **文件列表** — 显示当前目录下的文件和文件夹
- **操作栏** — 新建、上传、搜索、刷新等操作按钮
- **详情面板** — 显示选中文件的属性信息

### 文件列表信息

| 列 | 说明 |
|----|------|
| 名称 | 文件名或目录名，目录显示文件夹图标 |
| 大小 | 文件大小（目录不显示大小） |
| 修改时间 | 最后修改时间 |
| 权限 | 文件权限（如 rw-r--r--） |
| 所有者 | 文件属主和属组 |

### 导航操作

- 点击目录进入子目录
- 点击路径栏中的目录名快速跳转
- 点击"返回上级"回到父目录
- 直接在路径栏输入路径并回车跳转

## 文件操作

### 新建文件或目录

1. 点击"新建"按钮
2. 选择类型：文件或目录
3. 输入名称
4. 对于文件，可同时输入初始内容
5. 确认创建

### 编辑文件

1. 点击文本文件名称或选择"编辑"
2. 在代码编辑器中修改文件内容
3. 点击"保存"写入文件

> 支持编辑的文件类型：.txt、.html、.css、.js、.json、.yaml、.yml、.xml、.md、.conf、.ini、.sh、.py、.go、.php 等文本格式。二进制文件不可编辑。

### 重命名

1. 选中文件或目录
2. 点击"重命名"
3. 输入新名称
4. 确认

### 复制

1. 选中要复制的文件或目录（支持多选）
2. 点击"复制"
3. 输入目标路径
4. 确认复制

### 移动

1. 选中要移动的文件或目录
2. 点击"移动"
3. 输入目标路径
4. 确认移动

### 删除

1. 选中要删除的文件或目录（支持多选）
2. 点击"删除"
3. 在确认对话框中核对文件列表
4. 确认删除（不可恢复）

> **警告**：删除操作不可撤销，请谨慎操作。删除目录将递归删除目录下所有内容。

## 上传与下载

### 上传文件

1. 导航到目标目录
2. 点击"上传"按钮
3. 选择本地文件（支持多文件上传）
4. 等待上传完成

上传进度将实时显示，大文件上传可能需要较长时间。

### 下载文件

1. 选中文件
2. 点击"下载"按钮
3. 文件将开始下载到本地

> 仅支持下载单个文件。如需下载目录，请先压缩为 zip 再下载。

## 压缩与解压

### 压缩文件

1. 选中要压缩的文件或目录（支持多选）
2. 点击"压缩"按钮
3. 输入压缩包保存路径和文件名
4. 选择压缩格式（目前支持 zip）
5. 点击"压缩"开始

### 解压文件

1. 选中 .zip 压缩包
2. 点击"解压"按钮
3. 输入解压目标目录
4. 点击"解压"开始

## 文件搜索

### 基本搜索

1. 点击"搜索"按钮
2. 输入搜索关键词
3. 选择搜索起始目录（默认当前目录）
4. 点击搜索

搜索结果将显示匹配的文件路径，点击可直接跳转到该文件所在目录。

### 正则搜索

1. 在搜索框中输入正则表达式
2. 勾选"使用正则表达式"选项
3. 点击搜索

示例正则：
- `\.log$` — 匹配所有 .log 后缀文件
- `^config` — 匹配以 config 开头的文件
- `(nginx|apache)` — 匹配包含 nginx 或 apache 的文件

## 常见使用场景

### 场景一：部署网站文件

1. 导航到网站根目录（如 `/www/wwwroot/example.com`）
2. 点击"上传"，选择本地构建好的网站文件
3. 等待上传完成
4. 如有压缩包，上传后使用"解压"功能解压
5. 刷新网站确认部署成功

### 场景二：修改配置文件

1. 导航到配置文件所在目录
2. 点击配置文件进行在线编辑
3. 修改完成后点击"保存"
4. 前往对应模块重启服务使配置生效
5. 如修改出错，可重新编辑恢复

### 场景三：清理日志文件

1. 使用搜索功能查找 `.log` 文件
2. 按大小排序找到大文件
3. 选中不需要的日志文件
4. 点击删除（或先压缩备份再删除）
5. 在计划任务中配置定期清理，避免手动操作

### 场景四：备份网站目录

1. 导航到网站根目录的上级目录
2. 选中网站目录
3. 点击"压缩"，生成 zip 备份包
4. 下载备份包到本地保存
5. 或使用备份模块进行自动化备份
