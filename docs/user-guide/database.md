# 数据库管理

数据库管理模块提供 MySQL、PostgreSQL 和 Redis 三种数据库的完整管理能力，包括实例的创建与生命周期管理、库表操作、用户权限管理和 SQL 执行。所有数据库实例均以 Docker 容器方式运行。

## 功能概览

- **实例管理** — 创建、启动、停止、重启、删除数据库实例
- **库表管理** — 创建/删除数据库、查看表结构、浏览表数据
- **用户权限** — 创建数据库用户、授权/撤销权限
- **SQL 执行** — 在线执行 SQL 查询、导入/导出 SQL 文件
- **支持类型** — MySQL、PostgreSQL、Redis

## 实例管理

### 创建实例

1. 进入"数据库管理"页面，点击"创建实例"
2. 填写实例配置：

| 字段 | 说明 | 示例 |
|------|------|------|
| 类型 | 数据库类型 | mysql / postgres / redis |
| 版本 | 数据库版本 | mysql:8.0 / postgres:16 / redis:7 |
| 端口 | 宿主机映射端口 | 3306 / 5432 / 6379 |
| root 密码 | 管理员密码（MySQL/PostgreSQL） | 自定义强密码 |

3. 点击"创建"，系统将自动拉取镜像并启动容器
4. 创建完成后实例状态变为 `running`

> **注意**：首次创建某类型数据库时需要拉取 Docker 镜像，可能需要几分钟时间。

### 实例列表

实例列表展示所有数据库实例：

| 列 | 说明 |
|----|------|
| ID | 实例唯一标识 |
| 类型 | mysql / postgres / redis |
| 版本 | 数据库版本号 |
| 端口 | 宿主机映射端口 |
| 容器状态 | running / stopped / error |
| 创建时间 | 实例创建时间 |
| 操作 | 启动/停止/重启/管理/删除 |

### 实例操作

- **启动** — 启动已停止的数据库容器
- **停止** — 停止运行中的数据库容器
- **重启** — 重启数据库容器
- **删除** — 删除实例，可选是否同时删除数据卷（`cleanup=true`）

## 库表管理

点击实例的"管理"按钮进入数据库管理控制台。

### 数据库列表

展示该实例下的所有数据库，可执行：

- **创建数据库** — 填写数据库名、字符集（MySQL）、排序规则
- **删除数据库** — 删除指定数据库（不可恢复，请谨慎操作）

### 表列表

选择数据库后，展示该库下的所有数据表：

- 表名
- 引擎（MySQL）
- 行数
- 数据大小
- 创建时间

### 表结构

点击表名查看表结构详情：

- 字段名、类型、是否可空、默认值、注释
- 主键、索引、外键信息

### 表数据浏览

点击"数据"按钮浏览表中数据：

- 支持分页浏览
- 显示所有字段内容
- 每页默认 10 条，可通过 `page_size` 参数调整

## 用户权限管理

### 创建用户

1. 进入实例管理的"用户"标签页
2. 点击"创建用户"
3. 填写：
   - 用户名
   - 密码
   - 允许连接的主机（MySQL，默认 `%` 表示任意主机）
4. 点击创建

### 授权权限

1. 在用户列表中点击"授权"
2. 选择目标数据库
3. 勾选权限类型（如 SELECT、INSERT、UPDATE、DELETE、ALL PRIVILEGES 等）
4. 确认授权

### 撤销权限

1. 在用户列表中点击"撤销"
2. 指定数据库名
3. 确认撤销该用户在此数据库上的所有权限

### 删除用户

删除指定数据库用户，需指定用户名和主机（MySQL）。

## SQL 执行

### 在线执行 SQL

1. 进入实例管理的"SQL"标签页
2. 在编辑器中输入 SQL 语句
3. 选择目标数据库
4. 点击"执行"

#### 安全限制

- 默认禁止执行破坏性 SQL（DROP、TRUNCATE、DELETE 无 WHERE 等）
- 如需执行，需勾选"允许破坏性操作"（`allow_destructive=true`）
- 执行结果显示受影响行数或查询结果集

### 导入 SQL

1. 点击"导入"按钮
2. 选择目标数据库
3. 粘贴 SQL 内容或上传 .sql 文件
4. 系统将逐行执行 SQL 并返回执行结果

### 导出 SQL

1. 点击"导出"按钮
2. 选择数据库（必选）和表（可选，不选则导出整库）
3. 系统生成 `.sql` 文件并自动下载
4. 导出内容包含表结构和数据

## Redis 特殊说明

Redis 实例管理提供以下特有功能：

- **数据库列表** — Redis 默认 16 个数据库（0-15）
- **Key 浏览** — 查看指定数据库中的 Key，支持分页
- **Key 详情** — 查看 Key 的类型、TTL、值
- **Key 操作** — 删除 Key、设置 TTL
- **信息查看** — 查看 Redis 服务器信息（内存、连接数、命中率等）

## 常见使用场景

### 场景一：为网站创建数据库

1. 创建 MySQL 实例，设置端口和 root 密码
2. 进入实例管理，创建数据库（如 `myblog`）
3. 创建专用数据库用户（如 `blog_user`）
4. 为该用户授予 `myblog` 数据库的全部权限
5. 在网站配置中使用该用户和密码连接数据库

### 场景二：数据备份与迁移

1. 使用"导出"功能将数据库导出为 .sql 文件
2. 下载备份文件保存到安全位置
3. 在新服务器上创建数据库实例
4. 使用"导入"功能上传并执行 .sql 文件
5. 验证数据完整性

### 场景三：性能排查

1. 在 SQL 编辑器中执行 `SHOW PROCESSLIST`（MySQL）查看当前连接
2. 执行慢查询分析 SQL 定位性能瓶颈
3. 查看表结构确认索引是否合理
4. 使用 Redis 信息查看内存使用和命中率
