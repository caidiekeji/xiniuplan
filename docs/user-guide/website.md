# 网站管理

网站管理模块帮助您创建和管理基于 Nginx 的网站，支持静态站点、运行时站点和反向代理三种类型，提供 SSL 证书申请、配置编辑和访问日志查看功能。

## 功能概览

- 网站列表（分页、状态筛选）
- 创建网站（静态 / 运行时 / 反向代理）
- 网站启停和重启
- Nginx 配置在线编辑
- SSL 证书管理（手动上传 / Let's Encrypt 自动申请）
- 访问日志和错误日志查看

## 网站类型

| 类型 | 标识 | 说明 |
|------|------|------|
| 静态站点 | `static` | 纯 HTML/CSS/JS 静态文件，由 Nginx 直接提供服务 |
| 运行时站点 | `runtime` | 需要后端运行时（如 Node.js、PHP），通过容器运行 |
| 反向代理 | `reverse_proxy` | 将请求转发到后端服务（如内部应用、其他服务器） |

## 创建网站

### 操作步骤

1. 进入"网站管理"页面，点击"创建网站"按钮
2. 填写网站基本信息：
   - **主域名**：网站的主要访问域名（必填），如 `example.com`
   - **附加域名**：其他绑定域名，多个用逗号分隔，如 `www.example.com`
   - **网站类型**：选择 static / runtime / reverse_proxy
   - **根目录**：网站文件存放路径（静态站点必填）
   - **运行时**：运行时类型（runtime 类型必填）
   - **备注**：可选的网站描述
3. 点击"创建"，系统将自动生成 Nginx 配置并启动站点

### 创建后操作

网站创建成功后，您需要：

1. **上传网站文件** — 使用文件管理器将网站文件上传到根目录
2. **配置 DNS** — 将域名 A 记录指向服务器 IP
3. **申请 SSL** — 参考下方 SSL 证书管理章节
4. **测试访问** — 在浏览器中输入域名确认网站正常运行

## 网站列表

网站列表展示所有已创建的站点，包含以下信息：

| 列 | 说明 |
|----|------|
| ID | 站点唯一标识 |
| 主域名 | 网站主要域名 |
| 类型 | static / runtime / reverse_proxy |
| 状态 | running（运行中）/ stopped（已停止）/ error（异常） |
| SSL | 是否已启用 SSL |
| 创建时间 | 站点创建时间 |
| 操作 | 启动/停止/重启/配置/SSL/日志/删除 |

### 列表操作

- **启动** — 启动已停止的网站，重新加载 Nginx 配置
- **停止** — 停止网站，移除 Nginx 配置（不删除文件）
- **重启** — 重启网站，重新加载 Nginx 配置
- **删除** — 删除网站，可选是否同时删除网站文件

## Nginx 配置编辑

### 查看配置

在网站列表中点击"配置"按钮，可查看当前网站的 Nginx 配置内容。配置以代码编辑器形式展示，包含：

- 域名 server_name
- 监听端口（80 / 443）
- 根目录 root
- 索引文件 index
- SSL 证书路径（如已启用）
- 反向代理配置（如为 reverse_proxy 类型）

### 修改配置

1. 在配置编辑器中直接修改 Nginx 配置
2. 点击"保存"，系统将验证配置语法
3. 配置正确则自动 reload Nginx 使配置生效
4. 如配置有误，将显示错误信息，不会应用错误配置

> **注意**：修改配置前建议先备份原配置。错误的 Nginx 配置可能导致网站无法访问。

## SSL 证书管理

### 申请 SSL 证书

云枢面板支持两种 SSL 证书方式：

#### 方式一：Let's Encrypt 自动申请（推荐）

1. 确保域名已解析到服务器 IP
2. 在网站列表点击"SSL"按钮
3. 选择提供商 `letsencrypt`
4. 填写邮箱地址（用于接收证书到期提醒）
5. 点击"申请"，系统将自动完成域名验证和证书签发
6. 申请成功后自动启用 HTTPS 并配置自动续期

#### 方式二：手动上传证书

1. 准备好证书文件（.crt / .pem）和私钥文件（.key）
2. 在 SSL 管理页面选择提供商 `manual`
3. 粘贴证书内容和私钥内容
4. 点击"应用"，系统将保存证书并启用 HTTPS

### SSL 信息查看

点击"SSL"按钮可查看当前证书信息：

- 证书提供商
- 证书到期时间
- 自动续期状态
- 证书文件路径

## 访问日志

### 查看日志

在网站列表点击"日志"按钮，可查看网站的访问日志和错误日志：

| 日志类型 | 参数值 | 说明 |
|----------|--------|------|
| 访问日志 | `access` | 记录所有 HTTP 请求，包括 IP、URL、状态码、UA 等 |
| 错误日志 | `error` | 记录 Nginx 错误和上游服务错误 |

### 日志参数

- **日志类型**：选择 access 或 error
- **行数**：查看最近多少行日志，默认 100 行

日志以纯文本形式展示，支持滚动查看。

## 常见使用场景

### 场景一：部署静态博客

1. 创建网站，类型选择 `static`，填写域名和根目录
2. 使用文件管理器将 Hugo/Hexo 生成的静态文件上传到根目录
3. 申请 Let's Encrypt SSL 证书
4. 配置 DNS 解析，访问域名确认博客正常运行

### 场景二：反向代理内部应用

1. 创建网站，类型选择 `reverse_proxy`
2. 填写域名，在 Nginx 配置中设置 `proxy_pass http://127.0.0.1:3000`
3. 配置 WebSocket 支持（如应用需要）：
   ```nginx
   proxy_set_header Upgrade $http_upgrade;
   proxy_set_header Connection "upgrade";
   ```
4. 申请 SSL 证书，通过 HTTPS 安全访问内部应用

### 场景三：多域名绑定同一站点

1. 创建网站时在"附加域名"中填写多个域名
2. 或在 Nginx 配置的 `server_name` 中添加域名
3. 确保所有域名都已解析到服务器 IP
4. SSL 证书需覆盖所有域名（Let's Encrypt 支持多域名证书）
