# 容器管理

容器管理模块提供 Docker 容器和镜像的可视化管理能力，您可以查看容器列表、管理容器生命周期、查看容器日志和资源统计、浏览本地镜像，无需记忆复杂的 Docker 命令。

## 功能概览

- 容器列表（含已停止容器）
- 容器启动、停止、重启、删除
- 容器详情查看
- 容器日志查看（支持实时流式输出）
- 容器资源统计（CPU、内存）
- 本地镜像列表查看

## 前置条件

使用容器管理功能需要：

1. 服务器已安装 Docker
2. Docker 服务正在运行（`systemctl status docker`）
3. 运行云枢面板的用户具有 Docker 访问权限（通常需加入 `docker` 用户组）

如 Docker 未安装或不可用，容器列表将显示错误信息。

## 容器列表

进入"容器管理"页面，展示所有 Docker 容器（默认包含已停止的容器）。

### 列表字段

| 列 | 说明 |
|----|------|
| ID | 容器 ID（短格式，前 12 位） |
| 名称 | 容器名称 |
| 镜像 | 容器使用的镜像 |
| 状态 | 容器状态（running / exited / created 等） |
| 端口 | 端口映射信息 |
| 创建时间 | 容器创建时间 |
| 标签 | 容器 Labels |
| 操作 | 启动/停止/重启/日志/统计/删除 |

### 筛选

- 默认显示所有容器（包括已停止的）
- 可通过 `all=false` 参数仅显示运行中的容器

## 容器操作

### 启动容器

1. 在容器列表中找到已停止的容器
2. 点击"启动"按钮
3. 容器状态变为 `running`

### 停止容器

1. 找到运行中的容器
2. 点击"停止"按钮
3. 系统发送停止信号，容器优雅退出
4. 状态变为 `exited`

### 重启容器

1. 点击"重启"按钮
2. 系统先停止再启动容器
3. 适用于配置变更后需要重启的场景

### 删除容器

1. 找到要删除的容器
2. 点击"删除"按钮
3. 如容器正在运行，需先停止或使用强制删除（`force=true`）
4. 确认删除

> **注意**：删除容器不会删除容器使用的镜像和数据卷。如需同时清理，请使用系统清理功能。

## 容器详情

点击容器名称或"详情"按钮，查看容器详细信息：

- 容器完整 ID
- 容器名称
- 使用的镜像
- 当前状态和创建时间
- 端口映射
- 环境变量
- 挂载卷
- 网络配置
- Labels 标签

## 容器日志

### 查看日志

1. 在容器列表中点击"日志"按钮
2. 显示容器的标准输出和标准错误日志

### 日志参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| tail | 显示最后多少行日志 | 100 |
| follow | 是否实时流式输出新日志 | false |

### 实时日志

开启 `follow=true` 后，日志通过 SSE（Server-Sent Events）实时推送：

- 新日志行即时显示在页面上
- 适用于调试正在运行的应用
- 关闭页面或切换标签即停止流式输出

## 容器资源统计

点击"统计"按钮查看容器实时资源使用情况：

| 指标 | 说明 |
|------|------|
| CPU 使用率 | 容器 CPU 占用百分比 |
| 内存使用量 | 容器当前内存使用量 |
| 内存限制 | 容器内存上限 |
| 内存使用率 | 内存使用量 / 内存限制百分比 |

统计数据为实时采样值，刷新页面可获取最新数据。

## 镜像列表

切换到"镜像"标签页，查看本地所有 Docker 镜像：

| 列 | 说明 |
|----|------|
| ID | 镜像 ID |
| 标签 | 镜像标签（repository:tag） |
| 大小 | 镜像大小 |
| 创建时间 | 镜像创建时间 |

> 当前版本镜像管理为只读，可查看镜像列表。镜像拉取和删除功能可通过 Web 终端执行 `docker pull` / `docker rmi` 命令完成。

## 常见使用场景

### 场景一：排查容器启动失败

1. 在容器列表中找到状态为 `exited` 的容器
2. 点击"日志"查看容器输出，定位错误原因
3. 根据错误信息修复配置或代码
4. 点击"重启"重新启动容器
5. 再次查看日志确认启动成功

### 场景二：监控容器资源占用

1. 点击容器的"统计"按钮
2. 查看 CPU 和内存使用率
3. 如资源占用过高，查看日志确认是否有异常
4. 必要时调整容器资源限制（需通过 docker run 参数或 docker-compose）

### 场景三：查看应用实时日志

1. 点击运行中容器的"日志"按钮
2. 开启"实时输出"（follow=true）
3. 在浏览器中操作应用，观察日志实时输出
4. 调试完成后关闭页面即可停止日志流

### 场景四：管理数据库容器

云枢面板创建的 MySQL/PostgreSQL/Redis 实例均以 Docker 容器运行：

1. 在容器列表中可找到这些容器（名称通常包含数据库类型）
2. 可直接在此处启停数据库容器
3. 查看数据库容器日志排查连接问题
4. 查看资源统计确认数据库性能
