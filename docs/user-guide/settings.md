# 系统设置

系统设置模块提供面板全局配置管理，包括基本设置、SMTP 邮件配置、版本信息与更新检查、系统清理工具和详细系统信息，帮助您管理和维护云枢面板的运行。

## 功能概览

- 系统设置查看与修改
- SMTP 邮件配置与测试
- 版本信息查看
- 版本更新检查
- 系统清理工具
- 详细系统信息

## 系统设置

### 查看设置

进入"系统设置"页面，展示当前面板的所有配置项。设置以键值对形式存储，包含：

| 配置类别 | 配置项 | 说明 |
|----------|--------|------|
| 基本设置 | site_name | 面板名称 |
| 基本设置 | site_url | 面板访问地址 |
| 基本设置 | language | 默认语言 |
| 基本设置 | timezone | 系统时区 |
| 安全设置 | session_timeout | 会话超时时间（分钟） |
| 安全设置 | login_max_retries | 最大登录重试次数 |
| 安全设置 | password_min_length | 密码最小长度 |
| 监控设置 | monitor_interval | 监控采集间隔（秒） |
| 监控设置 | data_retention_days | 监控数据保留天数 |
| 备份设置 | backup_path | 备份文件存储路径 |
| 备份设置 | backup_retention_days | 备份保留天数 |
| 通知设置 | alert_enabled | 是否启用告警通知 |

### 修改设置

1. 在设置表单中修改需要调整的配置项
2. 点击"保存设置"
3. 系统验证配置有效性
4. 保存后立即生效（部分设置可能需要重新登录）

> 修改系统设置需要 `setting:update` 权限。管理员角色默认不包含此权限，仅超级管理员可修改系统设置。

## SMTP 邮件配置

SMTP 配置用于发送告警通知邮件、测试邮件等。

### 查看配置

展示当前 SMTP 配置：

| 配置项 | 说明 |
|--------|------|
| SMTP 服务器 | 邮件服务器地址 |
| 端口 | SMTP 端口（25/465/587） |
| 用户名 | SMTP 认证用户名 |
| 密码 | SMTP 认证密码（已脱敏显示） |
| 发件人地址 | 邮件发件人 |
| 发件人名称 | 发件人显示名称 |
| 加密方式 | SSL / TLS / 无 |

### 修改配置

1. 点击"编辑 SMTP 配置"
2. 填写邮件服务器信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| SMTP 服务器 | 邮件服务器地址 | smtp.qq.com |
| 端口 | 服务器端口 | 465 |
| 用户名 | 登录邮箱 | alert@example.com |
| 密码 | 邮箱授权码（非登录密码） | xxxxxxxxxxxxxxxx |
| 发件人地址 | 发件邮箱 | alert@example.com |
| 发件人名称 | 显示名称 | 云枢面板告警 |
| 使用 SSL | 是否启用 SSL | 是（465端口） |

3. 点击"保存"

### 发送测试邮件

1. 配置完成后点击"发送测试邮件"
2. 输入收件人邮箱地址
3. 点击"发送"
4. 系统发送测试邮件并返回结果
5. 检查收件箱是否收到测试邮件

> 如发送失败，请检查：SMTP 服务器地址和端口是否正确、用户名密码是否正确（部分邮箱需使用授权码）、服务器是否能访问 SMTP 端口、防火墙是否放行出站流量。

### 常用 SMTP 配置参考

## 版本信息

### 当前版本

展示面板版本信息：

| 项目 | 说明 |
|------|------|
| 版本号 | 当前安装的版本 |
| 构建时间 | 版本构建时间 |
| Git Commit | 对应的代码提交 |
| Go 版本 | 编译使用的 Go 版本 |

### 检查更新

1. 点击"检查更新"按钮
2. 系统连接更新服务器检查最新版本
3. 如发现新版本，显示版本号和更新内容
4. 如已是最新版本，提示"当前已是最新版本"

> 更新检查需要服务器能访问外部网络。如无法连接，请检查网络和防火墙设置。

## 系统清理

系统清理工具帮助您释放磁盘空间，清理不必要的临时文件和缓存。

### 清理类型

| 清理类型 | 标识 | 清理内容 |
|----------|------|----------|
| 临时文件 | `temp` | 系统临时目录（/tmp）中的过期文件 |
| 日志文件 | `logs` | 系统日志和应用日志的轮转旧文件 |
| Docker 缓存 | `docker` | Docker 未使用的镜像、容器、构建缓存 |
| 面板缓存 | `cache` | 面板运行产生的临时缓存文件 |
| 旧备份 | `old_backups` | 超过保留期限的备份文件 |

### 执行清理

1. 选择要清理的类型
2. 点击"执行清理"
3. 系统扫描并清理对应文件
4. 返回清理结果（释放空间大小、清理文件数）

> 清理操作不可撤销，请确认不需要相关文件后再执行。建议清理前先创建备份。Docker 缓存清理可能影响后续容器启动速度（需重新拉取镜像）。

## 常见使用场景

### 场景一：配置告警邮件

1. 进入系统设置 → SMTP 配置
2. 填写邮件服务器信息（以 QQ 邮箱为例）
3. 保存后点击"发送测试邮件"
4. 确认收到测试邮件
5. 前往告警通知模块创建通知渠道，选择邮件类型
6. 创建告警规则关联该渠道
7. 触发测试规则，确认收到告警邮件

### 场景二：磁盘空间不足清理

1. 仪表盘发现磁盘使用率过高
2. 进入系统设置 → 系统清理
3. 先执行"日志文件"和"临时文件"清理
4. 如空间仍不足，执行"Docker 缓存"清理
5. 查看清理结果确认释放空间
6. 如仍不足，使用文件管理器查找大文件
7. 在计划任务中配置定期清理任务

### 场景三：面板版本升级

1. 进入系统设置 → 版本信息
2. 点击"检查更新"
3. 如有新版本，查看更新内容
4. 升级前创建系统备份
5. 按照更新说明执行升级（通常替换二进制文件并重启服务）
6. 升级完成后刷新页面确认版本号
7. 测试各功能模块是否正常

### 场景四：修改面板基本信息

1. 进入系统设置
2. 修改面板名称为您的品牌名
3. 设置面板访问 URL（用于邮件中的链接）
4. 调整会话超时时间（如安全要求高可设为 15 分钟）
5. 调整监控采集间隔（如服务器性能有限可增大间隔）
6. 保存设置，刷新页面确认生效
