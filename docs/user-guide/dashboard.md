# 仪表盘使用

仪表盘是云枢面板的首页，提供服务器资源概览、监控图表和最近操作审计日志，帮助您快速掌握系统运行状态。

## 功能概览

仪表盘包含以下区域：

1. **资源概览卡片** — CPU、内存、磁盘、网络的实时使用率
2. **监控趋势图表** — 各资源指标的历史趋势曲线
3. **系统信息** — 操作系统、内核版本、运行时间、主机名等
4. **最近审计日志** — 最近的用户操作记录

## 资源概览

进入仪表盘页面后，顶部展示四个核心资源指标卡片：

| 指标 | 说明 | 数据来源 |
|------|------|----------|
| CPU 使用率 | 当前 CPU 整体使用率百分比 | 系统 `/proc/stat` |
| 内存使用率 | 已用内存 / 总内存百分比 | 系统 `/proc/meminfo` |
| 磁盘使用率 | 根分区已用空间百分比 | `df` 命令 |
| 网络流量 | 实时上传/下载速率 | 网络接口统计 |

每个卡片显示当前值和简短状态描述，当使用率超过阈值时会以警告色提示。

## 监控趋势图表

在资源概览下方，您可以查看各资源的历史趋势：

### 切换指标

通过指标选择器切换查看：
- **CPU** — 处理器使用率趋势
- **内存** — 内存使用量趋势
- **磁盘** — 磁盘 I/O 趋势
- **网络** — 网络入站/出站流量趋势

### 时间范围

支持以下时间范围：

| 范围 | 说明 | 数据粒度 |
|------|------|----------|
| 1h | 最近 1 小时 | 1 分钟 |
| 6h | 最近 6 小时 | 5 分钟 |
| 24h | 最近 24 小时 | 15 分钟 |
| 7d | 最近 7 天 | 1 小时 |

> 监控数据由后端采集器按 `config.yaml` 中 `monitor.interval`（默认 60 秒）定时采集并存储到 SQLite 数据库。

## 系统信息

仪表盘展示服务器基本信息：

- 主机名
- 操作系统名称和版本
- 内核版本
- 系统架构（x86_64 / aarch64 等）
- 运行时间（Uptime）
- CPU 型号和核心数
- 总内存
- 面板版本号

## 最近审计日志

仪表盘底部展示最近的用户操作审计日志，包括：

| 字段 | 说明 |
|------|------|
| 时间 | 操作发生时间 |
| 用户 | 执行操作的用户名 |
| 动作 | 操作类型（登录、创建、删除等） |
| 资源 | 操作对象 |
| IP | 操作者 IP 地址 |
| 结果 | 成功/失败 |

点击"查看全部"可进入完整的审计日志页面。

## 常见使用场景

### 场景一：排查服务器卡顿

1. 查看仪表盘 CPU 和内存使用率是否过高
2. 切换到 1h 时间范围观察趋势，确认是否为突增
3. 前往容器管理查看是否有异常容器占用资源
4. 使用 Web 终端执行 `top` / `htop` 进一步定位进程

### 场景二：监控磁盘空间

1. 查看磁盘使用率卡片，确认剩余空间
2. 切换到磁盘指标查看增长趋势
3. 使用文件管理器清理大文件或日志
4. 在计划任务中配置定期清理任务

### 场景三：追踪异常操作

1. 查看最近审计日志，发现可疑操作
2. 记录操作用户和时间
3. 前往 SSH 安全页面查看登录日志，确认是否有异常登录
4. 必要时修改密码、禁用对应用户
