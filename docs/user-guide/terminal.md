# Web 终端

Web 终端模块允许您直接在浏览器中使用 SSH 终端连接服务器，无需安装任何 SSH 客户端软件。终端基于 WebSocket 实现，支持实时交互、会话保持和终端大小自适应。

## 功能概览

- 浏览器内 SSH 终端
- WebSocket 实时双向通信
- 会话保持与恢复
- 终端窗口大小自适应
- 心跳保活机制
- 自动会话清理

## 打开终端

1. 在侧边栏点击"Web 终端"
2. 系统将自动建立 WebSocket 连接
3. 连接成功后显示终端界面，提示 `[终端已连接] session_id=xxx`
4. 此时即可在终端中输入命令

> 终端默认连接到 `localhost:22`，使用当前系统用户。如需连接其他服务器，请在 SSH 配置中调整。

## 终端操作

### 基本使用

终端的使用方式与普通 SSH 终端完全一致：

- 直接输入 Shell 命令并回车执行
- 支持方向键浏览历史命令
- 支持 Tab 自动补全
- 支持 Ctrl+C / Ctrl+Z / Ctrl+D 等控制字符
- 支持 vim、nano、htop、top 等交互式程序

### 终端大小调整

终端窗口大小会自动适应浏览器窗口。当浏览器窗口大小改变时，终端会自动发送 `resize` 消息调整 PTY 大小，确保全屏程序（如 vim、htop）正确显示。

### 会话保持

- 每个终端连接分配唯一的 `session_id`
- 网络中断后重新连接时，如传入相同的 `session_id`，可恢复之前的会话
- 恢复会话时显示 `[会话已恢复] <session_id>`
- 会话中运行的程序不会因短暂断连而终止

### 心跳保活

- 终端每 30 秒发送一次 WebSocket ping 保持连接
- 60 秒内未收到 pong 则认为连接断开
- 连接断开后终端会话保持 30 分钟，期间可恢复
- 超过 30 分钟未活跃的会话将被自动清理

## 技术实现

### 连接协议

终端通过 WebSocket 连接到后端：

```
GET /api/v1/ws/terminal?session_id=<可选>&cols=80&rows=24
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| session_id | 会话 ID，传入可恢复已有会话 | 空（创建新会话） |
| cols | 终端列数 | 80 |
| rows | 终端行数 | 24 |

### 消息格式

客户端和服务端通过 JSON 消息通信：

```json
{
  "type": "input",
  "data": "ls -la\n"
}
```

| 消息类型 | 方向 | 说明 |
|----------|------|------|
| input | 客户端→服务端 | 用户输入内容 |
| output | 服务端→客户端 | 终端输出内容 |
| resize | 客户端→服务端 | 调整终端大小（含 cols、rows） |
| error | 服务端→客户端 | 错误信息 |
| close | 客户端→服务端 | 关闭会话 |

非 JSON 格式的消息将被直接当作终端输入处理。

## 安全说明

- WebSocket 连接需要携带有效的 JWT Token（通过查询参数或 Cookie）
- 终端操作会被审计日志记录
- 建议生产环境使用 HTTPS + WSS 加密传输
- 终端权限等同于运行面板的系统用户，请谨慎授予终端访问权限

## 常见使用场景

### 场景一：快速执行系统命令

无需打开本地 SSH 客户端，直接在浏览器中执行 `df -h`、`free -m`、`systemctl status nginx` 等命令查看系统状态。

### 场景二：编辑配置文件

在终端中使用 `vim /etc/nginx/nginx.conf` 编辑配置文件，保存后执行 `nginx -t` 测试配置，再执行 `systemctl reload nginx` 重载。

### 场景三：运行交互式程序

使用 `htop` 查看实时进程和资源占用，使用 `iftop` 查看网络流量，使用 `vim` 编辑代码，这些交互式程序在 Web 终端中均可正常运行。

### 场景四：网络中断后恢复

执行长时间运行的命令（如编译、备份）时，即使浏览器标签页意外关闭，只要在 30 分钟内重新打开终端并恢复会话，命令仍在后台继续运行。
