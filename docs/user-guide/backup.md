# 备份恢复

备份恢复模块提供网站、数据库、应用和系统配置的备份与恢复能力，支持手动创建备份、查看备份历史、一键恢复和备份文件下载，帮助您保障数据安全。

## 功能概览

- 多类型备份（网站 / 数据库 / 应用 / 系统）
- 手动创建备份
- 备份列表与详情查看
- 一键恢复备份
- 备份文件下载
- 删除备份
- 可结合计划任务实现自动备份

## 备份类型

| 类型 | 标识 | 备份内容 |
|------|------|----------|
| 网站备份 | `site` | 网站文件目录 + Nginx 配置 |
| 数据库备份 | `database` | 数据库 SQL 导出文件 |
| 应用备份 | `app` | 应用数据目录 + 配置 |
| 系统备份 | `system` | 面板配置 + 系统设置 |

## 创建备份

### 操作步骤

1. 进入"备份恢复"页面，点击"创建备份"
2. 选择备份类型：
   - **网站备份** — 选择要备份的网站
   - **数据库备份** — 选择数据库实例和数据库名
   - **应用备份** — 选择已安装的应用
   - **系统备份** — 备份面板配置
3. 填写备注（可选，便于后续识别）
4. 点击"创建备份"
5. 系统开始执行备份，状态变为 `running`
6. 备份完成后状态变为 `success`，失败则变为 `failed`

### 备份过程

备份执行流程：

1. 创建备份记录，状态设为 `pending`
2. 开始执行，状态变为 `running`
3. 根据备份类型执行对应操作：
   - 网站：压缩网站根目录为 tar/zip 包
   - 数据库：执行 `mysqldump` / `pg_dump` 导出 SQL
   - 应用：压缩应用数据目录
   - 系统：导出面板配置和数据库
4. 保存备份文件到备份存储目录
5. 记录文件大小和路径
6. 状态更新为 `success` 或 `failed`

> 大文件备份可能需要较长时间，期间可正常使用面板其他功能。

## 备份列表

备份列表展示所有备份记录，支持按类型筛选：

| 列 | 说明 |
|----|------|
| ID | 备份唯一标识 |
| 类型 | site / database / app / system |
| 目标 | 备份对象名称（网站域名、数据库名等） |
| 大小 | 备份文件大小 |
| 状态 | pending / running / success / failed |
| 备注 | 创建时填写的备注 |
| 创建时间 | 备份创建时间 |
| 操作 | 详情/恢复/下载/删除 |

### 筛选

- 按备份类型筛选（`type=site` 等）
- 按状态筛选
- 支持分页浏览

## 备份详情

点击备份记录的"详情"按钮，查看备份详细信息：

- 备份 ID、类型、目标
- 备份文件路径
- 文件大小
- 当前状态
- 错误信息（如备份失败）
- 备注
- 创建时间

## 恢复备份

### 操作步骤

1. 在备份列表中找到要恢复的备份
2. 确认备份状态为 `success`
3. 点击"恢复"按钮
4. 在确认对话框中仔细阅读警告：
   - 恢复操作将覆盖当前数据
   - 建议恢复前先创建当前数据的备份
5. 确认恢复
6. 系统执行恢复操作
7. 恢复完成后提示成功

### 恢复说明

| 备份类型 | 恢复操作 |
|----------|----------|
| 网站 | 解压备份文件覆盖网站根目录，恢复 Nginx 配置 |
| 数据库 | 执行 SQL 文件导入到目标数据库 |
| 应用 | 解压备份文件覆盖应用数据目录 |
| 系统 | 导入面板配置和数据库 |

> **警告**：恢复操作会覆盖当前数据，不可撤销。恢复前务必备份当前数据。数据库恢复会清空现有数据后导入备份。

## 下载备份

1. 在备份列表中点击"下载"按钮
2. 浏览器开始下载备份文件
3. 文件格式取决于备份类型（.sql / .tar.gz / .zip）

建议定期下载重要备份到异地存储，防止服务器故障导致备份丢失。

## 删除备份

1. 选中要删除的备份（支持多选）
2. 点击"删除"按钮
3. 确认删除
4. 系统将删除备份记录和对应的备份文件

> 删除备份文件后不可恢复，请谨慎操作。建议保留至少最近 3 份备份。

## 自动备份（计划任务）

结合计划任务模块可实现自动备份：

1. 进入"计划任务"页面
2. 创建新任务，类型选择 `backup`
3. 配置备份类型和目标
4. 设置执行周期（如每天凌晨 3 点）
5. 启用任务
6. 系统将按计划自动创建备份

建议配置备份保留策略，定期清理旧备份以节省磁盘空间。

## 常见使用场景

### 场景一：网站改版前备份

1. 进入备份恢复，创建网站备份
2. 等待备份完成并下载到本地
3. 开始网站改版或升级
4. 如改版出现问题，使用备份一键恢复
5. 改版成功后，可保留备份一段时间再删除

### 场景二：数据库定期备份

1. 在计划任务中创建数据库备份任务
2. 设置每天凌晨执行
3. 备份文件自动保存到服务器
4. 定期下载备份到异地存储
5. 配置清理任务删除超过 30 天的旧备份

### 场景三：服务器迁移

1. 在原服务器上创建网站和数据库备份
2. 下载所有备份文件
3. 在新服务器上安装云枢面板
4. 上传备份文件到新服务器
5. 创建对应的网站和数据库
6. 使用备份恢复功能导入数据
7. 测试确认一切正常后切换 DNS

### 场景四：误操作恢复

1. 发现误删除了网站文件或数据库数据
2. 立即停止相关服务，防止数据被覆盖
3. 在备份列表中找到最近的成功备份
4. 点击恢复，选择对应的备份
5. 恢复完成后验证数据完整性
6. 分析误操作原因，避免再次发生
