# 云枢面板（犀牛面板）设计记忆 — .design-memory.md

> 维护者：设计助手 · 最近更新：2026-09-13

## 设计语言（已定，勿漂移）

**画面句**：凌晨的机房里，一排机柜指示灯在深墨蓝灰的钢板上安静闪烁，琥珀与青绿是仅有的两处亮色。

- **60%**：冷钢蓝基底（浅 #f4f6f9 / 暗 #0e1117）
- **30%**：同相分层面板面（surface/surface2/surface3）
- **10%**：信号青绿 #1ba784（CTA/焦点撞色）+ 信息蓝微点缀
- **语义色纪律**：ok=绿 / warn=琥珀 / err=红
- **签名元素**：状态指示灯 LED（青绿脉冲 2.5s / 红 1s 闪烁 / 熄灭=offline）——keyframes + token 化，全局可复用
- **动效语言**：仪表行为——快（150ms 微交互）/稳（300ms 状态）/ LED 常驻呼吸；reduced-motion 全局降级
- **等宽刻度**：数字一律 `.mono` + tabular-nums（仪表盘读数感）

## 组件清单

- 通用：PageCard / DataTable（scrollX 默认 700）/ SearchForm / ModalForm / StatusTag / StatCard（LED+lift）/ ConfirmDialog / CodeEditor(Monaco) / ErrorBoundary / RhinoLogo（唯一自定义 SVG，5 path）
- 2026-09 新增：DockerResources / ExecTerminal（xterm+WS exec）/ SecurityExtras

## 2026-09-13 设计审计结论（详见 docs/design-audit.md）

- 六维度评级 B+；修复 7 处：全局 focus-visible、卡片键盘态、移动端表格按钮 32px 可点高度、2 处 transition:all、SecurityExtras 间距 token 化、skip link、字体策略注释
- 待办：专属图标集（机柜/终端/数据库/证书锁/容器，sprite.svg）；宽表 scrollX 逐表核对

## 工程约定

- 字体：不加载 webfont，系统栈优先（首屏 <2s 优先），Inter/JetBrains Mono 仅为系统增强项
- 断点：768px 主断点（token + 布局 + 全局三层响应）；480px 小屏
- 所有新样式禁止硬编码间距/颜色，一律 var(--space-*/--line/--ink/...)
- Naive UI 覆盖集中在 main.css，主题经 data-theme + darkTheme 双轨
